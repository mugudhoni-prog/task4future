# Daily Punch

I need a app to punch my schedules & duties for the week and it should have each and everyday in it, so basically i will open it and the task will be there and i will click it or mark it as done and if it is not done the next day i should get a reminder of it and also with a motivational message so i won't be lazy again, I will be using it to add task like learn, gym, eat, walk, run and other daily task and it should also keep a track on the data and give a weekly and monthly report on how efficient and consistent i am - the days will be there i should click and open each day and mark my task, also use calendar for ref, the ui and ux can be simple and creative with dark theme
